# BPM Slash（拍點斬）

一款在瀏覽器執行的 2D 橫向卷軸節奏動作遊戲。你操控一個拿著劍的火柴人，只有三個動作：**向左、向右、攻擊**。
不論你什麼時候按下攻擊鍵，揮劍的「命中瞬間」一定會被鎖在歌曲 BPM 的半拍格線上；怪物、地磚、尖刺與背景也全部跟著 4/4 拍脈動。

- 純 HTML5 Canvas 2D + Web Audio API，原生 ES Modules
- 零外部相依、無建置步驟
- 預設附一首原創 88 BPM 歌曲，也可以上傳自己的 WAV / MP4

## 如何執行

```bash
npm start
```

然後用瀏覽器開啟 <http://localhost:5173>（可用 `PORT=8080 npm start` 更改連接埠）。需要 Node.js 18 以上（開發環境為 Node 22）。

> 由於使用 ES Modules 與 `fetch`，必須透過 HTTP 伺服器開啟，直接雙擊 `index.html` 不會運作。

## 操作

| 動作 | 鍵盤 | 手機 |
|---|---|---|
| 向左 / 向右 | `←` `→` 或 `A` `D` | 畫面左下方按鈕 |
| 攻擊 | `J`、`K` 或 `空白鍵` | 右下方「斬」按鈕 |
| 暫停 / 繼續 | `Esc` 或 `P` | 上方中央暫停鈕 |

建議手機橫向遊玩。

## 前拍 / 後拍系統

每一拍被切成兩個「半拍 slot」：

- **前拍**（正拍，on-beat）：整數拍上的 slot
- **後拍**（反拍，off-beat，八分音符的 "&"）：兩拍中間的 slot

按下攻擊後，系統會把你的輸入吸附到最近的可用 slot，命中瞬間（hitbox、傷害、特效）就發生在該 slot 的時間點。攻擊音效則直接排程在音訊時鐘上的精確時間，所以聽起來一定和音樂對齊。

| 招式 | 觸發 | 效果 |
|---|---|---|
| 前拍斬 | 偶數 slot | 橫向重斬，傷害 2，距離 78 px |
| 強拍斬 | 前拍且為小節第 1 拍 | 傷害 3，距離 96 px，小幅震屏 |
| 後拍刺 | 奇數 slot | 快速突刺，傷害 1，距離 92 px，**可穿透盾兵的盾** |
| 八分連斬 | 連續 4 個半拍都有攻擊（前後前後） | 第 4 擊傷害 ×2，距離 160 px |
| 小節終結 | 同一小節 4 個前拍都出手且沒有後拍 | 第 4 擊放出衝擊波，260 px 內全體敵人受到 4 點傷害 |

判定（依與拍點的誤差）：PERFECT ≤ 45 ms（×1.5）、GREAT ≤ 90 ms（×1.25）、GOOD ≤ 140 ms（×1.0）、AUTO（×0.75，仍會自動對拍命中，只是沒有加成）。
稍晚按下時，只要晚於拍點不超過「延遲容許」（預設 40 ms），仍算命中前一個拍點；設為 0 即嚴格模式。最多同時排定 2 個尚未命中的攻擊。

評級：`(PERFECT + GREAT) / 總攻擊數` ≥ 0.85 且未死亡為 S，≥ 0.70 為 A，≥ 0.50 為 B，其餘為 C。

## 敵人與地形（全部鎖拍）

- **史萊姆**（HP 2）：每拍朝你跳一下。
- **蝙蝠**（HP 1）：隨拍上下飛，第 3 拍預警，第 4 拍俯衝。
- **盾兵**（HP 4）：第 1、3 拍前進；前拍攻擊從正面會被格擋（BLOCK），後拍刺可穿透；第 3 拍舉劍，第 4 拍劈下。
- **節拍尖刺**：第 3 拍發光預警，第 4 拍升起，下一小節第 1 拍收回。
- 地磚隨拍彈跳並形成漣漪，強拍時邊緣亮起；背景的霓虹城市與等化器柱也跟著跳動。

## BPM、偏移與上傳歌曲

1. 在選單按「上傳 WAV / MP4」選擇檔案（解碼失敗請改用 WAV 或 AAC 編碼的 MP4；上傳的檔案不會被保存）。
2. 設定 **BPM**（40 – 240，可到 0.1）。可以直接輸入、拖曳滑桿、用 **Tap Tempo**（跟著歌曲連續點擊，取最近 8 次間隔的平均，超過 2 秒沒點就重置），或按 **自動偵測** 取得建議值後再按「套用」。
3. 設定 **第一拍偏移**（ms）：歌曲檔案中第 1 拍所在的位置，可用 ±10 ms 按鈕微調。
4. 按 **試聽對拍**：從頭播放歌曲並疊加節拍器，調整 BPM 或偏移會即時生效，用耳朵確認是否對齊。
5. 若覺得判定總是偏早或偏晚，用 **輸入延遲校正**（正值表示你習慣按得晚，系統會把輸入往前修正）。

其他設定：量化模式（八分 = 前拍＋後拍；四分 = 僅前拍）、節拍器開關、音樂 / 音效音量、減少閃爍（關閉螢幕閃光與震屏）。設定會存在瀏覽器的 `localStorage`。

## 時間模型

唯一的時鐘是 `AudioContext.currentTime`：畫面用 `getOutputTimestamp()` 平滑換算，鍵盤事件用 `event.timeStamp` 換算成音訊時間。節拍事件、敵人動作、尖刺與生怪都只在節拍事件觸發；不使用 `setTimeout` / `Date.now()` / 累加 `dt` 推算節拍（節拍器的 lookahead 排程器只用計時器來「喚醒」，排程時間一律由音訊時鐘計算）。詳見 `docs/DESIGN.md`。

## 測試

```bash
npm test
```

會以 Node 內建 test runner 執行 `tests/` 底下所有 `*.test.mjs`（`js/core/` 皆為純函式，可在 Node 中單元測試）。

自動化稽核（需要 Playwright）：`npm run audit:rhythm`。
